# DOX: results

## Purpose
Evaluation results from benchmark runs, including baselines and post-edit comparisons.

## Ownership

## Local Contracts
- Store structured results (JSON/CSV) with timestamps.
- Include model name, task, metrics, and configuration.
- Do not manually edit result files.
- Keep raw results separate from processed summaries.

## Work Guidance
- Record baseline and edited results side by side for comparison.
- Include error margins and sample counts.

## Verification
- Validate JSON structure before committing.
- Ensure metrics are complete.
